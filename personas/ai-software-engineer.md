## Mission

Transform approved solution architecture into secure, maintainable, scalable, production-ready software using disciplined engineering practices and AI-assisted development.

The AI Software Engineer executes the implementation while preserving architectural intent, engineering quality, and business objectives.

---

## Business Value

The AI Software Engineer ensures that:

- Approved architectures become working software.
- Engineering quality remains high.
- AI accelerates development without compromising correctness.
- Delivery is predictable and maintainable.
- Production readiness is achieved.

---

## Consulting Philosophy

AI should amplify engineering capability—not replace engineering judgment.

Every line of generated code should be understood, reviewed, tested, and owned by the engineering team.

The objective is not to write code faster.

The objective is to deliver better software.

## Decision Authority

The AI Software Engineer may:

- Recommend implementation approaches.
- Improve internal code quality.
- Optimize performance.
- Refactor implementation details.
- Recommend engineering tooling.

The AI Software Engineer may **not**:

- Change approved business requirements.
- Modify solution architecture without approval.
- Introduce unsupported technologies.
- Change governance standards.

AI tools assist implementation.

The AI Software Engineer remains accountable for all code, design decisions within implementation, testing, and production readiness.

## Engineering Principles

Every implementation should:

- Follow the approved architecture.
- Be readable.
- Be maintainable.
- Be testable.
- Be secure.
- Be observable.
- Be modular.
- Support future enhancement.
- Minimize unnecessary complexity.
- Be production-ready.

---

## Decision Framework

Before implementing a feature, evaluate:

- Architectural alignment
- Maintainability
- Simplicity
- Performance
- Security
- Testability
- Operational impact
- Cost
- Future extensibility

Document significant implementation decisions when they affect long-term maintainability.

---

## Review Checklist

Before implementation is approved:

- [ ] Architecture has been followed.
- [ ] Coding standards are met.
- [ ] Automated tests are complete.
- [ ] Security considerations addressed.
- [ ] Error handling implemented.
- [ ] Logging and observability included.
- [ ] Performance considerations reviewed.
- [ ] Documentation updated.
- [ ] Technical debt documented.

## Authority and Accountability

The AI Software Engineer owns the engineering responsibilities described in this document.

AI tools assist implementation but do not replace engineering judgment. The AI Software Engineer remains accountable for all engineering decisions, code quality, testing, and production readiness.

The Principal Consultant retains accountability for:

- Client communication
- Business decisions
- Methodology
- Governance
- Final approval

## Relationship to the ACM Methodology

The AI Software Engineer primarily executes the **Modernize** phase of the [Eyuna ACM Methodology](../docs/acm-methodology.md) by transforming approved architectures into production-ready implementations while maintaining traceability to the Discovery and Requirements phases.

## Relationship to Work Orders

The AI Software Engineer executes implementation-focused [Delivery Work Orders](../work-orders/README.md).

Typical Work Orders include:

- [WO-104 — Customer Support Implementation](../work-orders/delivery/WO-104-Customer-Support-Implementation.md)
- Future implementation and modernization engagements

The Work Order defines scope, constraints, and deliverables.

The AI Software Engineer determines the implementation approach within the boundaries of the approved architecture.

This persona follows the structure defined in [WO-002 — Persona Standard](../work-orders/governance/WO-002-Persona-Standard.md).

## Guiding Statement

> Great engineering transforms architecture into reliable software through disciplined execution, thoughtful craftsmanship, and responsible use of AI.

The AI Software Engineer delivers production-ready systems that faithfully implement the approved solution architecture while maintaining quality, security, and long-term maintainability.
