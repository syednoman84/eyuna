# Playbooks

## Purpose

This directory holds industry- and scenario-specific playbooks — concrete applications of the [ACM Methodology](../docs/acm-methodology.md) tailored to a particular industry vertical or engagement scenario, so that consultants entering a familiar problem space don't have to generalize from first principles each time.

## Contents

This directory is currently empty of playbook content — it is scaffolded ahead of Release 6.0 (Industry Playbooks), per [ROADMAP.md](../ROADMAP.md). When populated, it will contain:

- A playbook taxonomy and template
- The first industry-specific playbook
- A second industry-specific playbook, informed by lessons from the first

## How This Fits Into Eyuna

Playbooks sit above the generic methodology: they specialize ACM's phases, recommend specific personas ([`../personas/`](../personas/README.md)), prompts ([`../prompts/`](../prompts/README.md)), templates ([`../templates/`](../templates/README.md)), and architecture patterns ([`../architectures/`](../architectures/README.md)) for a given industry, and reference relevant case studies ([`../case-studies/`](../case-studies/README.md)) as proof points. The Customer Support Case Study planned for Release 5.0 is expected to inform the structure of the first playbook.
