# Glossary

> **Status:** Placeholder — not yet authored. Tracked under Release 1.0 in [ROADMAP.md](../ROADMAP.md).

## Purpose of This Document

This document will provide shared definitions for terms used consistently across Eyuna, so that personas, prompts, templates, playbooks, and case studies all use the same vocabulary with the same meaning. Expected initial entries include terms such as:

- **ACM** — the AI Consulting Methodology defined in [`acm-methodology.md`](acm-methodology.md)
- **Engagement** — a discrete unit of consulting work delivered using Eyuna
- **Persona** — a defined role used consistently across engagements (see [`../personas/`](../personas/README.md))
- **Playbook** — an industry- or scenario-specific application of ACM (see [`../playbooks/`](../playbooks/README.md))
- **Reference Architecture** — a reusable, validated architecture pattern (see [`../architectures/`](../architectures/README.md))

## Why It Matters

A consulting framework used by multiple people over multiple years will drift in terminology unless key terms are defined once and referenced everywhere else. This glossary is that single source of truth.
