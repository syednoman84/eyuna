# Scripts

## Purpose

This directory holds automation and maintenance scripts for the Eyuna repository itself — scripts that keep the repository consistent and well-formed, as distinct from the consulting-workflow tooling in [`../tools/`](../tools/README.md).

## Contents

This directory does not yet contain scripts. When populated, it will hold scripts such as:

- Link checkers for cross-references between README files
- Directory structure or naming-convention validators
- Scaffolding scripts for adding new personas, prompts, templates, or playbooks consistently

## How This Fits Into Eyuna

As Eyuna grows across many directories and years of contributions, manual consistency checks (relative links, naming conventions, required README sections) become error-prone. Scripts here exist to automate those checks and keep the repository's structural quality bar consistent, supporting the governance model defined in [`../docs/governance.md`](../docs/governance.md).
