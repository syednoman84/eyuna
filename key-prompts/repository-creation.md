You are the Lead Platform Engineer for a new open-source project called "Eyuna."

## Context

Eyuna is not an application.

It is a consulting operating system.

Its purpose is to provide a reusable framework for AI consulting engagements.

It will eventually contain:

- Consulting methodologies
- Personas
- Prompt libraries
- Templates
- Industry playbooks
- Architecture patterns
- Reference implementations
- Starter projects
- Case studies
- Website content
- LinkedIn content
- GitHub projects

Think of this project as the internal operating manual for a world-class AI consulting company.

The repository should be designed to scale over many years.

Do NOT generate actual consulting content yet.

Instead, initialize a professional repository that is easy to navigate, well documented, and ready for future growth.

## Repository Quality

Design this repository like a mature open-source framework.

Requirements:

- Clean structure
- Consistent naming
- Professional documentation
- Markdown best practices
- Relative links between README files where appropriate
- Table of contents for larger documents
- Future-proof organization

Do not create unnecessary nesting.

Avoid empty directories where Git cannot track them. If a directory would otherwise be empty, include an appropriate README.md or .gitkeep file.
