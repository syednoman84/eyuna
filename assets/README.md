# Assets

## Purpose

This directory holds shared media and design assets used across Eyuna — diagrams, logos, images, and other non-text files referenced by documentation, templates, playbooks, and content.

## Contents

This directory does not yet contain assets. When populated, it will hold shared visual assets organized by type or usage (e.g., logos and brand assets, architecture diagrams, template graphics).

## How This Fits Into Eyuna

Assets are referenced by other directories rather than duplicated within them — a diagram used in an architecture pattern ([`../architectures/`](../architectures/README.md)) and again in a case study ([`../case-studies/`](../case-studies/README.md)) or a piece of external content ([`../content/`](../content/README.md)) should live here once, and be linked from wherever it's used. This keeps binary and media files out of documentation directories and avoids duplication as the same visual is reused across the framework.
